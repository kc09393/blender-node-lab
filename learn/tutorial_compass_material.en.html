Compass Material: Pointing a Fixed Direction with Vector Math

Fresnel-driven effects only ever depend on camera angle — the bright edge always follows the camera as you orbit. But if you want an effect that stays fixed to a chosen direction in object space (like a fixed glowing marker on an object) regardless of camera movement, you need a different technique: Vector Math's Dot Product measures how closely the surface normal aligns with a direction you pick — the closer, the brighter. This tutorial builds that effect, and shows how to extract a frequently-tuned parameter into its own Value node.

1. Step 1: Measure Normal-vs-Fixed-Direction Alignment with Vector Math

Add a Texture Coordinate and connect its Normal output to Vector Math's first vector input.

Set the operation to Dot Product.

Manually fill the second vector input with a direction, e.g. (0.4, 0.7, 0.5) — this is the fixed direction you want the effect to point at, unaffected by camera movement.

The dot product result: closer to 1 when the surface normal aligns with this direction, closer to 0 when perpendicular, and closer to -1 when opposite.

2. Step 2: Rescale the Dot Product to 0-1 with Map Range

Add a Map Range node and connect Vector Math's Value output to its value input.

Set From Min to -1 and From Max to 1, keeping the target at 0 to 1.

Since the dot product's raw range is -1 to 1, skipping this rescale would waste half the downstream Color Ramp's range on negative values (which just get clamped to 0).

3. Step 3: Extract a 'Sharpness' Parameter with a Value Node

Add a Value node set to 6 — this number will control how tight and sharp the glowing spot is.

Add a Math node with operation Power.

Connect Map Range's result to the Math node's first value, and the Value node to its second value (the exponent).

Power pushes values already close to 1 to stay close to 1, while pushing everything else lower — a bigger exponent (the Value node) makes the glowing spot tighter and smaller. Extracting it into its own Value node means you can retune sharpness without touching the Math node itself.

4. Step 4: Feed a Color Ramp and Emission, Add on Top of the Base Material

Add a Color Ramp, connect the Math node's result to its Fac, and set it up so most of it stays black with only values near 1 lighting up.

Add an Emission node, connect the Color Ramp's color to it, and raise Strength (e.g. to 4).

Add an Add Shader, connect the original material to one input and the new Emission to the other, then wire its output to the material output.

Orbit the camera around the sphere: the glowing spot should stay fixed at the same place on the sphere (tied to the object, not the camera angle) — completely unlike a Fresnel-driven effect.
