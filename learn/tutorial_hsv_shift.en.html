Hue Shift: One-Click Recolor

Use the Hue Saturation Value node to adjust color — more intuitive than editing RGB directly. Turning Hue alone can flip red to blue without retuning three channels.

Open the interactive tutorial 繁體中文
Intermediate4 steps

1. Step 1: Add a Hue Saturation Value Node

Drag in a Hue Saturation Value node from the Color category.

2. Step 2: Connect to Base Color

Connect its Color output to Principled BSDF's Base Color.

3. Step 3: Turn the Hue

Change Hue from the default 0.5 to a different value (e.g. 0.15). The color should shift to a different spot on the color wheel.

Much more intuitive than adjusting R/G/B separately.

4. Step 4: Raise Saturation

Raise Saturation above 1.3 — the color becomes more vivid and saturated instead of a dull gray tone.
