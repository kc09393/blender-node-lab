沃羅諾伊馬賽克：隨機色塊拼貼

沃羅諾伊紋理（Voronoi Texture）的 Color 輸出會給每個細胞一個獨立的隨機顏色，很適合做馬賽克磁磚、卵石地板這種「每一塊顏色都不太一樣」的效果——這跟石頭教學用 Distance 做斑駁色調是完全不同的技巧。

開啟互動教學 English
中階4 個步驟

1. 第一步：加入沃羅諾伊紋理

從「紋理 Texture」分類拖入沃羅諾伊紋理（Voronoi Texture）。

2. 第二步：接上座標

加入紋理座標（Texture Coordinate，輸入 Input 分類），把它的 Generated 輸出接到沃羅諾伊紋理的向量（Vector）。

3. 第三步：接 Color 而不是 Distance

這次把沃羅諾伊紋理的顏色（Color）輸出（不是距離 Distance）接到原理化 BSDF（Principled BSDF）的底色（Base Color）。

每一格細胞現在應該各自是一個隨機的純色。

4. 第四步：調高縮放做出更多小磁磚

把縮放（Scale）調到 8 以上，磁磚會變得更小更密集，更像真的馬賽克拼貼。
