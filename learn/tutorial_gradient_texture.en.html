Gradient Texture: The Simplest Texture Node

Gradient Texture has no complex parameters — it's just a smooth black-to-white transition along a direction. The simplest way to understand that a texture node's output is really just a 0-to-1 value.

Open the interactive tutorial 繁體中文
Beginner3 steps

1. Step 1: Add a Gradient Texture

Drag in a Gradient Texture from the Texture category and connect it to Principled BSDF's Base Color. The default is Linear, so the sphere should fade from black to white across one axis.

2. Step 2: Switch to Spherical

Change Type to Spherical. The gradient should now radiate outward from a center point in rings, instead of fading in a single direction.

Note: Radial is a different type — it sweeps by angle around the center (like a clock hand), not the ring-expansion effect used here. Don't mix the two up.

3. Step 3: Color It with a Color Ramp

Add a Color Ramp, connect Gradient Texture's Fac to its Fac, then connect the Color Ramp's Color to Base Color instead — turning the plain black/white gradient into any color scheme you like.
