Hand-Built Clearcoat: How Principled BSDF Works Under the Hood

Principled BSDF's Clearcoat isn't magic — it's really just 'blend two materials by Fresnel': a matte Diffuse BSDF underneath, a near-mirror Glossy BSDF on top, with the top coat becoming more visible at grazing angles. This tutorial builds that effect by hand from 3 primitive nodes (Diffuse BSDF / Glossy BSDF / Fresnel), and along the way introduces the two most basic constant nodes in any material graph: RGB and Value.

1. Step 1: Feed the Base Color with an RGB Node

Add an RGB node (Input category) and pick a color (e.g. deep red).

Connect it to Diffuse BSDF's Color input.

Unlike picking a color directly on Diffuse BSDF, RGB is a standalone node — if the same color needs to feed multiple places later, you only need to change it here once.

2. Step 2: Add Glossy BSDF as the Top Coat

Add a Glossy BSDF, set its color to white, and set Roughness near 0 (nearly mirror-like).

This layer represents the transparent clearcoat on top of the paint. Don't connect it anywhere yet — the next step needs it.

3. Step 3: Drive Fresnel's IOR with a Value Node

Add a Value node and set it to 1.5 (a typical IOR for automotive clearcoat).

Add a Fresnel node and connect the Value node to its IOR input — if multiple places later need this same IOR, you only need to change the Value node once.

4. Step 4: Blend Both Layers by Fresnel with Mix Shader

Add a Mix Shader.

Connect Diffuse BSDF (base paint) to the first Shader input, Glossy BSDF (clearcoat) to the second.

Connect Fresnel's Fac to Mix Shader's Fac.

Connect Mix Shader's output to the material output.

Orbit the preview: head-on should mostly show the base paint's color and matte texture, while edges get progressively brighter and mirror-like — this is exactly what Principled BSDF's Clearcoat socket does under the hood.
