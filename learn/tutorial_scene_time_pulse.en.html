Blender 5.2 Scene Time: A Pulsing Emissive Material

Use Blender 5.2 LTS's new Scene Time shader node to turn continuously increasing time into a repeating pulse for an animated emissive material.

Open the interactive tutorial 繁體中文
Beginner3 steps

1. Step 1: Add Scene Time

Drag Scene Time from the Input category.

Connect Seconds to Emission's Strength.

The preview gets brighter over time, but it does not loop yet.

2. Step 2: Make It Loop with Sine

Insert a Math node and set Operation to Sine.

Reconnect the chain as Seconds → Sine → Emission Strength.

Sine oscillates from -1 to 1, so the brightness starts pulsing.

3. Step 3: Keep Brightness in a Useful Range

Insert Map Range between Sine and Emission Strength.

Set From to -1..1, To to 0.25..5, and enable Clamp.

This removes negative brightness and keeps the pulse within a useful range.
