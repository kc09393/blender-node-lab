Separate/Combine XYZ: Stretch Just One Axis

Use Separate XYZ to split a coordinate into three independent values, operate on just one axis, then rejoin with Combine XYZ — the standard pattern when you only want to adjust one direction.

Open the interactive tutorial 繁體中文
Beginner4 steps

1. Step 1: Add Texture Coordinate and Separate XYZ

Drag in a Texture Coordinate (Input category) and a Separate XYZ (Converter category), then connect Texture Coordinate's Generated output to Separate XYZ's Vector input.

2. Step 2: Scale Up the Y Component with Math

Add a Math node, set its operation to Multiply, connect Separate XYZ's y output to its first value, and set the second value to 3.

3. Step 3: Rejoin with Combine XYZ

Add a Combine XYZ, connect Separate XYZ's x output to its x, and the Math node's result to its y.

This produces a coordinate where x is unchanged but y is scaled 3x.

4. Step 4: Feed a Checker Texture to See the Effect

Add a Checker Texture, connect Combine XYZ's Vector output to its Vector input, then feed it to Principled BSDF's Base Color.

The checker cells should stretch into rectangles along Y, not squares — proof that only the Y axis was scaled.
