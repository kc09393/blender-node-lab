Two-Tone Fabric: Recoloring the Whole Pattern with HSV

Once you've built a two-tone weave pattern, switching its colorway (say, blue-and-white to green-and-white) doesn't require re-tuning every Color Ramp stop — pipe a Hue Saturation Value node afterward, turn Hue, and the whole colorway shifts at once while keeping the original contrast and pattern. This tutorial demonstrates that 'separate the pattern from its colorway' technique.

1. Step 1: Build a Two-Tone Weave with Noise + Hard-Edge Ramp

Add a Noise Texture with a higher Scale (e.g. 22) for a fine texture. Add a Color Ramp, switch Interpolation to Constant, with two stops: position 0 dark blue, position 0.5 near-white.

The hard transition creates a clear dark/light interlocking pattern, like woven fabric threads.

2. Step 2: Connect to Base Color and Confirm the Pattern

First connect Color Ramp's Color directly to Principled BSDF's Base Color, and confirm the pattern is a clear dark-blue/white interlocking weave, not a soft gradient.

3. Step 3: Insert Hue Saturation Value

Insert a Hue Saturation Value node between Color Ramp and Principled BSDF: connect Color Ramp's Color to its Color input, then connect its Color output to Principled BSDF's Base Color, replacing the direct connection.

4. Step 4: Turn Hue for a New Colorway, Saturation for Vividness

Move Hue away from the default 0.5 (e.g. to 0.15) — the dark blue shifts to a different hue (e.g. green) as a set, while the contrast between the two tones and the pattern itself stay completely unchanged.

Because Hue rotates the whole image's hue uniformly rather than re-tuning any single stop.

Then raise Saturation (e.g. to 1.3) for a more vivid, saturated variant — no need to go back and edit the Color Ramp at all.
