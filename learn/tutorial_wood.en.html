Blender 5.0 Guided Tutorial

Make Procedural Wood Grain

Chain Wave Texture, Color Ramp, and Principled BSDF together to create wood grain without any image textures.

Open the interactive tutorial 繁體中文
Intermediate4 steps

1. Step 1: Add a Wave Texture

Drag in a Wave Texture from the Texture category — its bands are a great starting point for tree rings.

2. Step 2: Wire Up Coordinates

Add a Texture Coordinate (Input category) and connect its Generated output to Wave Texture's Vector input.

3. Step 3: Color It with Color Ramp

Add a Color Ramp (Converter category), connect Wave Texture's Fac to Color Ramp's Fac, then set the start color to dark brown and the end color to light brown.

4. Step 4: Feed Base Color

Connect Color Ramp's Color output to Principled BSDF's Base Color to finish the wood material.
