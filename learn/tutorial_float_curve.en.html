Curve Editor: Invert Roughness

Drag out a custom value-mapping curve with the Float Curve node to flip Noise Texture's light/dark relationship entirely — see how the curve editor is more flexible than Color Ramp or Map Range.

Open the interactive tutorial 繁體中文
Intermediate4 steps

1. Step 1: Add a Noise Texture

Drag in a Noise Texture from the Texture category — we'll feed its noise into the curve.

2. Step 2: Add a Float Curve

Drag in a Float Curve from the Converter category and connect Noise Texture's Fac to its Value input.

3. Step 3: Feed Roughness

Connect Float Curve's Value output to Principled BSDF's Roughness.

The default curve is a diagonal line — it doesn't change the value yet.

4. Step 4: Drag the Curve Into Reverse

On the Float Curve node card, drag the bottom-left control point to the top-left, and the top-right point to the bottom-right — the curve flips from rising to falling.

Areas that were brighter in the noise now get lower roughness (smoother) instead.
