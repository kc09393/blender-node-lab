Wavelength Node: Laser Spectrum Colors

The Wavelength node converts a visible-light wavelength (in nanometers) directly into the corresponding RGB color — useful for simulating lasers or prism dispersion where physically accurate coloring matters.

Open the interactive tutorial 繁體中文
Intermediate4 steps

1. Step 1: Add a Wavelength Node

Drag in a Wavelength node from the Converter category. The default 500nm is roughly green light.

2. Step 2: Add Emission and Connect to Output

Drag in an Emission node and connect it to Material Output's Surface.

3. Step 3: Feed Wavelength Into Emission's Color

Connect the Wavelength node's Color output to Emission's Color.

4. Step 4: Dial In a Red Laser's Wavelength

Set Wavelength between 630-700nm — the range of a common red laser pointer. The color should turn a saturated red.

Try 450nm for blue or 580nm for yellow.
