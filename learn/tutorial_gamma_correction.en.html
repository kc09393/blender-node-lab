Gamma: A Power-Curve Midtone Adjustment

The Gamma node simply computes pow(color, gamma) — values above 1 darken midtones, below 1 brighten them. Commonly used to correct texture data or quickly reshape a material's tonal curve.

Beginner3 steps

1. Step 1: Add a Gamma Node

Drag in a Gamma from the Color category and connect it to Principled BSDF's Base Color. Keep Color at mid-gray (0.5, 0.5, 0.5).

2. Step 2: Lower Gamma to Brighten

Set Gamma below 0.5 (e.g. 0.35). The mid-gray should visibly brighten.

An exponent below 1 lifts values within the 0-1 range upward overall.

3. Step 3: Try a Gamma Above 1

Now set Gamma above 2 — the color should become much darker than mid-gray.

This confirms Gamma is a power operation, not addition/subtraction — more extreme values have a stronger effect.
