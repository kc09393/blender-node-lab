Get to Know Noise Texture: Detail, Distortion, and Type

Noise Texture is the starting point for nearly every procedural material, but it's hard to picture what Detail/Roughness/Distortion actually do, or how the 5 Noise Types differ, just from their names. This tutorial adjusts them one at a time so you can see directly.

Open the interactive tutorial 繁體中文
Beginner4 steps

1. Step 1: Add a Noise Texture

Drag in a Noise Texture from the Texture category and connect its Color output to Principled BSDF's Base Color.

The default fBM type gives a soft, cloud-like pattern.

2. Step 2: Raise Detail for More Complexity

Raise Detail above 6.

Detail is the octave count: each extra octave layers in a finer level of pattern, so higher values look more layered and complex (at the cost of more computation).

3. Step 3: Add Distortion to Break Up Regularity

Raise Distortion above 2.

Distortion first warps the coordinate itself using another layer of noise, then samples using the warped coordinate — the pattern becomes more irregular and organic, useful for breaking up patterns that look too uniform.

4. Step 4: Switch Type to Multifractal

Switch Type to Multifractal.

Unlike the default fBM, which adds amplitude layer by layer, Multifractal multiplies them — the result is usually brighter with stronger contrast than fBM, another common basis for terrain or cloud generation.
