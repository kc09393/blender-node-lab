Torn Holes: Partial Transparency

Torn leaves, moth-eaten fabric, rusted-through sheet metal — these 'mostly solid, holes here and there' materials all use the same technique: Transparent BSDF as the 'hole', Mix Shader to blend it with the base material, and a Color Ramp mask to control where the holes appear. This tutorial focuses on Transparent BSDF, a node not used elsewhere in this site.

Intermediate3 steps

1. Step 1: Build a Hole Mask from Voronoi Distance

Add a Voronoi Texture.

Add a Color Ramp.

Connect Voronoi's Distance output to the Color Ramp's Fac input.

Set it up so position 0 is white, position 0.12 is black, and position 1 is also black. Since Distance is 0 at each cell center and rises quickly away from it, only a small area near each cell center stays white — those white spots become the holes.

2. Step 2: Add Transparent BSDF as the Hole

Add a Transparent BSDF. This node has no parameters — anywhere it's used, the surface becomes fully see-through.

Don't connect it anywhere yet — the next step needs it.

3. Step 3: Combine Both with Mix Shader

Add a Mix Shader.

Connect the original leaf material to the first Shader input.

Connect Transparent BSDF to the second Shader input.

Connect the Color Ramp's Color output to Mix Shader's Fac.

Since the Color Ramp is mostly black (0, fully the first material) with only the holes white (1, fully Transparent BSDF), this creates a 'mostly solid, holes in a few spots' look.

Connect Mix Shader's output to the material output.
