Blackbody Node: Warm Candlelight

Use the Blackbody node to convert color temperature (K) — the unit photographers and lighting artists actually use — directly into a physically accurate color, for a candlelight-warm glow.

Open the interactive tutorial 繁體中文
Intermediate4 steps

1. Step 1: Add a Blackbody Node

Drag in a Blackbody node from the Converter category. Temperature defaults to 5500K (close to midday daylight).

2. Step 2: Add Emission and Connect to Output

Drag in an Emission node and connect it to Material Output's Surface.

3. Step 3: Feed Blackbody Into Emission's Color

Connect Blackbody's Color output to Emission's Color.

4. Step 4: Dial In Candlelight's Temperature

Set Temperature between 1800-2200K — the color temperature of a real candle flame. The color should shift to an obvious warm orange, very different from the default white.
