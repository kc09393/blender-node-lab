Terrain Coloring: A Multi-Stop Ramp Plus Detail Overlay

Game art often auto-colors terrain with a single 'height → color' ramp: low = water, mid = grass, high = snow. This tutorial uses a Noise Texture to stand in for height, feeds it through a 6-stop Color Ramp for a water/sand/grass/rock/snow palette, then screens in a detail texture on top — showing how large-scale color zoning and small-scale surface detail can coexist.

1. Step 1: Use Noise Texture to Stand In for Height

Add a Noise Texture with a low Scale (e.g. 2.5) so it varies gently — more like large-scale terrain undulation than fine speckle.

2. Step 2: Build a 5+ Stop Terrain Color Ramp

Add a Color Ramp, connect Noise's Fac to its Fac, and build at least 5 stops: deep blue (water) → light blue (shallows) → sandy tan → grass green → rock grey → snow white, ordered low to high. This 'one ramp, whole terrain palette' technique is extremely common in game art.

3. Step 3: Screen In a Layer of Surface Detail

Add another Noise Texture as a detail pattern, with a high Scale (e.g. 18) so it varies finely. Add a Mix Color node — A from the Color Ramp's color, B from this detail noise's color, mode Screen, Fac low (e.g. 0.25). Screen only brightens, so this adds fine surface variation without wrecking the terrain's color zoning.

4. Step 4: Connect to Base Color to Finish

Connect the Mix Color node's output to Principled BSDF's Base Color. You should see both the large-scale water/sand/grass/rock/snow zoning and fine, small-scale surface variation at once — two scales of detail coexisting, not just one.
