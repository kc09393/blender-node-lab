Blender 5.2 LTS Guided Tutorial

Make a Stone Material

Use Voronoi Texture's cellular pattern to create a mottled stone look, driving both color and roughness from the same data so the cracks read as more realistic.

Open the interactive tutorial 繁體中文
Intermediate5 steps

1. Step 1: Add a Voronoi Texture

Drag in a Voronoi Texture from the Texture category — its cell boundaries are a great basis for stone-surface cracks.

2. Step 2: Wire Up Coordinates

Add a Texture Coordinate (Input category) and connect its Generated output to Voronoi Texture's Vector input.

3. Step 3: Color It with Color Ramp

Add a Color Ramp (Converter category) and connect Voronoi's Distance output to Color Ramp's Fac.

The cell-center distance becomes color variation, creating a mottled stone tone.

4. Step 4: Feed Base Color

Connect Color Ramp's Color output to Principled BSDF's Base Color.

5. Step 5: Vary Reflectivity at the Cracks

Connect Voronoi's Distance output with a second wire to Principled BSDF's Roughness (one output can feed multiple destinations).

Now roughness varies at the cell cracks too — closer to real stone than a single uniform roughness value.
