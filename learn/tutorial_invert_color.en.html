Invert Color: Instant Complementary Masks

Invert Color computes 1 minus the original value — commonly used to flip a black/white mask, e.g. turning 'where there's noise' into 'where there isn't', without touching the upstream nodes at all.

Open the interactive tutorial 繁體中文
Beginner3 steps

1. Step 1: Add a Checker Texture

Drag in a Checker Texture from the Texture category and connect it to Principled BSDF's Base Color for now — take note of which squares are black and which are white.

2. Step 2: Insert an Invert Color

Drag in an Invert Color from the Color category and insert it between Checker Texture and Base Color — Checker's Color output feeds Invert's Color input, and Invert's output feeds Base Color.

3. Step 3: Confirm the Colors Swapped

Check the live preview — squares that were black should now be white, and vice versa.

Without touching a single setting on the Checker Texture itself, Invert Color alone did the swap.
