Vector Curves: Nonlinearly Warp a Normal

Vector Curves is the same concept as RGB Curves, but applied to a vector (like a normal) instead of a color — enabling more nuanced direction warping than a linear operation.

Open the interactive tutorial 繁體中文
Advanced3 steps

1. Step 1: Add a Noise Texture and Bump

Add a Noise Texture and a Bump node, connect Bump's output to Principled BSDF's Normal, and wire Noise directly into Bump's Height for now.

2. Step 2: Insert Vector Curves

Insert Vector Curves between Noise Texture and Bump — connect Noise's Fac to Vector Curves' Vector input, and Vector Curves' output to Bump's Height.

3. Step 3: Compress the Curve's Range

Drag the Vector Curves control points into a flatter (lower-slope) line, e.g. from (-1,-1)/(1,1) to (-1,-0.3)/(1,0.3).

The bump's relief should become subtler and softer instead of a rigid linear intensity.
