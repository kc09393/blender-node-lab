Make a Glowing Sign Effect

Drive Emission's brightness with a Wave Texture pattern to create a neon sign that glows unevenly — bright in some areas, dark in others — instead of a flat uniform glow.

Open the interactive tutorial 繁體中文
Beginner4 steps

1. Step 1: Add an Emission Node

Drag in an Emission node from the Shader category and connect it to Material Output's Surface — it should glow uniformly for now.

2. Step 2: Add a Wave Texture for the Pattern

Drag in a Wave Texture from the Texture category and set its Wave Type to Rings — we'll use its banding pattern to control where it glows brightest.

3. Step 3: Wire Up Coordinates

Add a Texture Coordinate (Input category) and connect its Generated output to Wave Texture's Vector input.

4. Step 4: Drive Strength with Fac

Connect Wave Texture's Fac output to Emission's Strength, replacing the fixed slider value.

The surface should now glow brighter and dimmer following the wave pattern — a neon look instead of flat uniform light.
