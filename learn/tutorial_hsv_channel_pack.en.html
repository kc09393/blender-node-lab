Separate Color: Adjust Only Saturation

Separate Color and Combine Color now support HSV/HSL modes, letting you split hue, saturation, and value apart and adjust just one. Here we boost only saturation on a Voronoi Texture's random cell colors, making them more vivid without touching hue or brightness.

Intermediate4 steps

1. Step 1: Add a Voronoi Texture

Drag in a Voronoi Texture from the Texture category. Its Color output gives each cell a random color — great for testing a saturation tweak.

2. Step 2: Split HSV with Separate Color

Add a Separate Color (Converter category), switch its Mode to HSV, and connect Voronoi Texture's Color to its Color input.

The three outputs will relabel themselves to Hue (H)/Saturation (S)/Value (V).

3. Step 3: Boost Saturation with a Math Node

Add a Math node (Converter category), set its operation to Multiply, connect Separate Color's Saturation (S) output to its first value, and set the second value to 2 or higher (e.g. 2.5). Turn on Clamp to keep it in range.

This amplifies saturation while leaving hue and value completely untouched.

4. Step 4: Reassemble with Combine Color

Add a Combine Color, also set to HSV mode. Connect Separate Color's Hue to its first input, the boosted saturation to its second input, and Separate Color's Value to its third input — then connect Combine Color's Color output to Principled BSDF's Base Color.

The result should look noticeably more vivid, while the pattern (hue distribution) looks exactly the same.
