Vector Displacement

Uses a vector map to describe exactly which direction and how far each point should move.

Try it in the sandbox 繁體中文

Beginner explanation

More flexible than Displacement — it can push in any direction, not just outward. Often paired with vector displacement maps baked from sculpting software.

Technical notes

Socket defaults match Blender 5.2.2, including Midlevel 0 and Scale 0.01, with Tangent, Object, and World space modes. Object space maps directly; Tangent space builds a stable orthogonal basis from the vertex normal, while World space rotates the vector back through the model matrix. These live conversions are suitable for teaching previews, but do not include Blender's custom mesh tangents or full non-uniform-scale correction.
