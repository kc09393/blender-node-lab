Texture Coordinate

Provides several coordinate systems to feed into a Texture node's Vector input.

Try it in the sandbox 繁體中文

Beginner explanation

Texture nodes default to UV if Vector is left unconnected. This node lets you switch to other coordinate systems — most commonly Generated (follows the object's shape, ignores UV) and Object (follows the object itself, unaffected by its transform).

Technical notes

This sandbox's preview meshes don't store separate Generated/Object coordinate data, so the Generated/Object/Window outputs are approximated as UV for now — only UV and Normal are computed exactly. Reflection approximates the view direction reflected off the normal.
