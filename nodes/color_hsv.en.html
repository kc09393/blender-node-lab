Hue Saturation Value

Adjusts hue, saturation, and value independently — more intuitive than tweaking RGB directly.

Try it in the sandbox 繁體中文

Beginner explanation

Hue rotates the color around the color wheel (e.g. turning red into blue), Saturation controls vividness (0 = grayscale), Value controls brightness. All three default to a 'no change' midpoint (Hue=0.5, Saturation=1, Value=1).

Technical notes

Implemented with the standard RGB↔HSV conversion formulas, consistent with Blender's color science. The Fac socket controls how much of the adjustment is applied (0 = no effect).
