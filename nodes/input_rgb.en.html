RGB

A fixed color value — the most basic color source in a material graph.

Try it in the sandbox 繁體中文

Beginner explanation

Click the swatch to pick a color; the output is exactly that color, ready to plug into any color socket.

Technical notes

Unlike picking a color directly on a socket, RGB is a standalone node — the same color value can feed multiple destinations, and changing it once updates them all.
