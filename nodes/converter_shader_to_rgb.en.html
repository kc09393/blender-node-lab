Shader to RGB

Bakes an already-lit shader result into a plain color, so it can be post-processed (e.g. toon quantization).

繁體中文

Beginner explanation

Common use: place after a Diffuse BSDF to convert its lit result into a color, then quantize it into a few tones with Color Ramp for a toon look.

Technical notes

This requires hooking in *after* full lighting is computed — the opposite of this sandbox's current 'compute material params, then let Three.js light it' architecture. A planned future upgrade.

Blender compatibility

Documentation only · requires Blender scene/render data
