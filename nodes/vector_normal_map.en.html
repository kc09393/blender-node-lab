Normal Map

Reads a tangent-space normal map texture for finer bump detail than Bump alone.

Try it in the sandbox 繁體中文

Beginner explanation

Usually placed after an Image Texture (with color space set to Non-Color). The purple-blue image is actually encoded normal directions, giving finer detail than a plain grayscale height.

Technical notes

The standard approach needs precomputed tangent/bitangent vertex attributes. This sandbox instead reuses the Bump node's screen-space derivative trick (a cotangent frame built from dFdx/dFdy of position and UV) to orient the tangent-space normal map correctly without extra vertex data — the effect matches Blender, though the implementation differs.
