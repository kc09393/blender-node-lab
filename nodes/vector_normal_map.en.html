Normal Map

Reads a tangent-space normal map texture for finer bump detail than Bump alone.

Try it in the sandbox 繁體中文

Beginner explanation

Usually placed after an Image Texture (with color space set to Non-Color). The purple-blue image is actually encoded normal directions, giving finer detail than a plain grayscale height.

Technical notes

Blender 5.1 added an OpenGL/DirectX convention switch; the two differ in the direction of the green Y component. This sandbox now flips the green channel in DirectX mode too. It still builds the tangent basis from screen-space derivatives, matching the effect with a different implementation.
