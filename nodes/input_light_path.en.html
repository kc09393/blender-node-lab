Light Path

Detects whether the current ray is a reflection, refraction, shadow ray, etc. — only meaningful in a path-traced renderer.

繁體中文

Beginner explanation

Often used to make a material show an effect only when directly seen by the camera, but not in reflections (e.g. hiding certain effects from mirror reflections).

Technical notes

This node's meaning is built on a per-ray path-tracing architecture. This sandbox uses real-time rasterization, which has no concept of 'which bounce this ray is'. Documentation only.
