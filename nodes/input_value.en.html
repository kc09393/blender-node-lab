Value

A fixed number — the most basic value source in a material graph.

Try it in the sandbox 繁體中文

Beginner explanation

Outputs a number you set — plug it into any float socket, e.g. to share one Roughness value across several material branches.

Technical notes

Extracting a commonly-used number into its own Value node means you only need to change it in one place later — a common material-graph organization technique.
