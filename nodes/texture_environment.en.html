Environment Texture

Wraps a full panorama around the scene — usually used as background and reflection source.

繁體中文

Beginner explanation

Similar to Image Texture, but maps a full 360° panorama using equirectangular projection.

Technical notes

This sandbox currently uses a fixed procedural environment (Three.js RoomEnvironment) for reflections and doesn't yet support uploading a custom HDRI panorama. Documentation only for now.
