Object Info

Provides object-level scene info: location, color, a random per-object value.

繁體中文

Beginner explanation

The Random output is most useful: it lets the same material look slightly different on each object it's applied to (e.g. randomly picking a brick tone).

Technical notes

Requires info about multiple distinct scene objects. This sandbox only previews a single object, so there's nothing to compare 'between objects'. Documentation only.
