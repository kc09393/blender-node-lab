UV Map

Selects which UV map on the object to use.

Try it in the sandbox 繁體中文

Beginner explanation

When an object has multiple UV maps (e.g. one for texturing, one for baked lighting), use this node to pick which one.

Technical notes

This sandbox's preview meshes only have one built-in UV set, so this node always outputs the same coordinate as Texture Coordinate's UV.
