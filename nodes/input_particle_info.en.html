Particle Info

Provides per-particle age, location, velocity, and other data from a particle system.

繁體中文

Beginner explanation

Often used to change a particle's (e.g. falling leaves, sparks) color or transparency based on how long it's existed.

Technical notes

Requires particle system simulation data, which this sandbox doesn't have. Documentation only.
