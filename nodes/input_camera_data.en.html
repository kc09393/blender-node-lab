Camera Data

Provides vectors and distances relative to the current camera.

繁體中文

Beginner explanation

View Z Depth is commonly used for depth-of-field or distance fog — the further from the camera, the stronger the effect.

Technical notes

This sandbox's camera changes live as the user drags to orbit/zoom, which could make learners mistakenly think 'the material itself changed'. Documentation only for now.
