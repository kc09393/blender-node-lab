Attribute

Reads custom vertex/face/instance attribute data stored on the object.

繁體中文

Beginner explanation

For advanced users: if you've stored custom data via Geometry Nodes or vertex groups (like a per-vertex wetness value), this node reads it into your material.

Technical notes

Requires custom vertex attribute data that this sandbox doesn't have. Documentation only.
