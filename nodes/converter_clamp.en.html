Clamp

Restricts a value to a min/max range, keeping it inside a sensible bound.

Try it in the sandbox 繁體中文

Beginner explanation

Many sockets (like Roughness) expect 0-1, but math upstream can push values outside that range. Clamp forces the value back into the range you specify.

Technical notes

Type has 2 options matching Blender: Min Max (default — clamps directly between Min and Max, assuming Min ≤ Max) and Range (automatically swaps the two before clamping if Min exceeds Max — useful when Min/Max come from upstream nodes and their order isn't guaranteed). Formulas verified against Blender's GPU shader source (`gpu_shader_material_clamp.glsl`).
